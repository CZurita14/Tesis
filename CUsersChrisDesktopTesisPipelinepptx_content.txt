Objetivo General
Implementar un dashboard para el monitoreo y control de datos de contaminación por residuos textiles en la empresa Faditex, usando un modelo de Machine Learning, con la finalidad de visualizar la cantidad de residuos textiles generados en el área de producción.

=== DIAPOSITIVA 17 ===
Objetivos Específicos
Analizar la situación actual de generación de residuos textiles y la precisión en sus registros manuales, para establecer una línea base de impacto ambiental.
Diseñar una arquitectura sólida que integra hardware de sensorización y protocolos de comunicación para el análisis de datos.
Desarrollar e implementar un pipeline de procesamiento de datos en Python y el modelo predictivo Random Forest para una estimación de desperdicios generados.
Validar el funcionamiento del pipeline y el modelo predictivo mediante comparaciones con Kpi’s, en un dashboard visual, validando el pipeline predictivo.
